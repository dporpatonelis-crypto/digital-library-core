# Digital Library Core

Η αποθήκη της ψηφιακής βιβλιοθήκης για τα βιβλία μαθητή και τα αυτοτελή, διαδραστικά μαθήματα HTML.

## Περιεχόμενα

- `books/`: τα CSV βιβλίων που υπήρχαν ήδη στο αποθετήριο.
- `lessons/`: οι τρέχουσες αυτοτελείς δραστηριότητες HTML.
- `catalog.json`: κατάλογος βιβλίων και διαδραστικών μαθημάτων.
- `index.html`: σελίδα περιήγησης στον κατάλογο.

Οι δραστηριότητες ανοίγουν online μέσω jsDelivr από το GitHub, χωρίς να χρειάζεται πρώτα λήψη από το Drive. Το Πιλοτήριο μπορεί να ενσωματώνει απευθείας τις διευθύνσεις του πεδίου `url` του `catalog.json`.

## Προσθήκη ή αντικατάσταση HTML

1. Αποθήκευσε το αυτοτελές αρχείο στο `lessons/` με σταθερό, λατινικό όνομα.
2. Πρόσθεσε ή ενημέρωσε την εγγραφή του στο `catalog.json` (`id`, `title`, `subject`, `file`, `size_bytes`, `url`, `github_url`).
3. Για το `url` χρησιμοποίησε τη μορφή `https://cdn.jsdelivr.net/gh/dporpatonelis-crypto/digital-library-core@main/lessons/<όνομα>.html`.
4. Κάνε commit και push στο `main`. Η νέα έκδοση διατίθεται από το CDN μετά την ενημέρωση της προσωρινής μνήμης του.

Το αποθετήριο είναι δημόσιο: κάθε HTML που προστίθεται εδώ είναι δημόσια προσβάσιμο. Τα πρωτότυπα αρχεία στο Drive παραμένουν στη θέση τους και δεν αλλάζουν δικαιώματα πρόσβασης.
