# Ψηφιακή Βιβλιοθήκη Μαθημάτων

Εικονογραφημένος κατάλογος αυτοτελών, διαδραστικών μαθημάτων HTML. Η επιλογή μιας κάρτας ανοίγει απευθείας το μάθημα, έτοιμο για χρήση στον browser.

[Άνοιγμα της βιβλιοθήκης](https://dporpatonelis-crypto.github.io/digital-library-core/)

## Προσθήκη ή ενημέρωση μαθήματος

1. Αποθήκευσε το HTML στον φάκελο `lessons/` με σταθερό, λατινικό όνομα.
2. Ετοίμασε μια μικρογραφία WebP 640 × 360 από την εικονογράφηση ή από στιγμιότυπο του μαθήματος. Βάλ’ τη στον φάκελο `assets/lesson-covers/`.
3. Πρόσθεσε ή ενημέρωσε την εγγραφή στον πίνακα `lessons` του `catalog.json`. Τα πεδία `file` και `thumbnail` έχουν σχετικές διαδρομές, όπως `lessons/example.html` και `assets/lesson-covers/example.webp`. Το `url` είναι η δημόσια διεύθυνση του μαθήματος στο GitHub Pages και το `github_url` δείχνει στο αρχείο του κλάδου `main`.
4. Για τοπική προεπισκόπηση, εκτέλεσε `python3 -m http.server 8000` από τη ρίζα του repo και άνοιξε τη σελίδα στην τοπική διεύθυνση [localhost:8000](http://localhost:8000/).
5. Η συγχώνευση στο `main` ενεργοποιεί το υπάρχον GitHub Pages workflow.

Κάθε μάθημα που προστίθεται στο αποθετήριο είναι δημόσια προσβάσιμο.
